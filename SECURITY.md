# Security policy

**PLIUM is currently a Windows preview, not a signed public release.**

For a reproducible security issue, use the repository's **[private vulnerability reporting](https://github.com/ardss/PLIUM/security/advisories/new)** if enabled. Otherwise open a public [Issue](https://github.com/ardss/PLIUM/issues) asking for a private contact method **without publishing exploit details, credentials, tokens, local clipboard history or private screenshots**.

Supported for security fixes: the latest development preview (currently 0.4.0-plium.10 (source preview)). Older original Edge-Drop releases and their tags are maintained by the original project, not PLIUM.

Security reports should include the operating system, current version, reproducibility and impact, but should not include real user data. Reports are triaged before making public commitments.
