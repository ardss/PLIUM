# PLIUM · 独立版本与发布制度

最后修订：2026-11-18。适用于 [ardss/PLIUM](https://github.com/ardss/PLIUM)。

## 产品身份与版本

PLIUM（叠间）基于 Edge-Drop（Apache-2.0）独立维护：`com.ardss.plium` / `PLIUM.exe` / `%APPDATA%\plium`。产品身份、数据、发布地址与上游分开；不继承上游版本号。

旧 `0.4.0-plium.N` 和 `1.0.0-beta.N` 是内部候选。首个自主公开版本预定为 **`v1.0.0`**。一条 Git SHA 对应一套不可变安装包、SHA-256、验收报告、回滚工件。禁止同名覆盖已公开资产，也不为单次微小修复反复发包。

## 工作流程

1. **DEV（Windows B）**：开发、审查和隔离资料测试。日常提交不触发 Windows A 安装。
2. **INTEGRATION（单一 PR）**：整合已确认范围，核验完整测试、类型检查、依赖安全、GitHub Windows CI。
3. **QA 候选**：冻结提交与安装包，使用合成资料验证启动、触顶、托盘、快捷键、文本/图片/文件导入和拖出、一行/三行、异常退出与恢复。
4. **Windows A 验收**：先备份完整用户目录（包括加密索引、Local State、payloads、images），保持一套安装、一个主实例；测多屏/DPI、冷启动、自启动、真实交互和回滚。不拿 B 的测试充当 A 的证据。
5. **GO / RELEASE**：同一源码、同一安装包、同一验收证据 + 清晰公开说明后才创建不可变 `v1.0.0` Tag 和 GitHub Release。自动更新仍关闭。

## 未签名公开版（用户已决定）

**2026-11-18 用户决定签名不作为首版发布门禁。** 允许未签名 Windows 安装包，但 README、GitHub Release 和安装说明必须明确：

> 此安装包未进行发行商代码签名。Windows 可能显示“未知发行商”，Microsoft Defender SmartScreen 可能发出警告。请仅从本项目的官方 GitHub Release 获取并核对 SHA-256，自行判断是否安装。本项目不宣称微软认证或 SmartScreen 信任。

不得建议关闭 Defender 或绕过安全措施。未来要做签名时再参阅 `CODE-SIGNING-POLICY.md`，与本次验收分开。

## 发布门禁

| 主题 | 必须核查 |
|---|---|
| 源码/安全 | 实际 SHA 与 CI、生产依赖审计、已知构建链例外治理、Git 历史扫描 |
| 数据 | 完整备份、同版升级不丢历史、异常退出恢复、二次清除确认、回滚工件 |
| 真实桌面 | 触顶/收回、一行⇄三行、托盘左/右/双击、Alt+C、原生拖拽、焦点、冷启动 |
| 多屏幕 | 目标显示器、工作区变化、缩放不同、单安装单实例 |
| 发行 | 安装包 SHA、版本、许可证、发布说明、未签名警示、下载与回滚 |
| 用户影响 | 不在用户操作时劫持鼠标/键盘，不将私人剪贴板资料放入测试、CI 或公共 Issue |

未测即未通过；不能因为 CI 绿色就推断所有真实交互可靠。

## 防止重复发版

将日常提交与交付彻底解耦。一个里程碑维护一条集成线，集中处理阻断性回归，其他功能移至下一期。不要因小 UI 改动升级版本、重装到 A。每次保存明确的源码/安装包哈希与证据，历史包归档不丢弃。以 `docs/RELEASE-STATUS.md` 作为唯一当前台账，首版 PR #29 与 Issue #18 作为追踪入口。
